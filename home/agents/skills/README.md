# Active skills

The eight primary workflows are `code`, `frontend`, `writing`, `motion`, `performance`, `security`, `growth`, and `media`.

Keep automatic discovery precise. A workflow owns the requested result; specialist material is loaded only when its procedure helps the current task. Child reviews and checkpoints feed that result without creating redundant interviews or approval gates.

Specialists live at `~/.agents/skill-modules/<name>/SKILL.md`. Only the eight workflows are exposed for automatic discovery; modules, including `taste-craft` and `unslop`, stay in the specialist library. A module is not a required stage just because it is installed.

Use `beast skills` to inspect the current active set. Select optional modules with `beast install --packs=…`; they are loaded by path, not promoted into top-level skills. Managed system/plugin skills and project-local skills remain owned by their respective installers or projects.
