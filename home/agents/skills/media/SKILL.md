# Media

Own the artifact from the supplied material and brief to a usable, inspected output. Use existing context to determine audience, format, duration, output location, and constraints. Ask only when a missing choice materially changes production.

## Choose the tool for the artifact

- A film, short, or launch video from a prompt with no existing project: `~/.agents/skill-modules/drawing-canvas-films/SKILL.md`. Every frame is drawn in code, and its look loop checks the frames at full size. Use its treatment step as the creative brief.
- Video production or an existing video project: inspect the project and available media tools; use the established stack and its version-matched documentation.
- 3D shots inside a film: `~/.agents/skill-modules/3d-scenes/SKILL.md`.
- Lottie: `~/.agents/skill-modules/text-to-lottie/SKILL.md`.
- Generated or edited raster images: the available image-generation skill/tool.
- Audio, captions, or other media: inspect existing assets and available purpose-built tools; preserve the user's original files and use the smallest reliable pipeline.
- Product UI motion belongs to the frontend/motion workflows, not a video-production workflow.

Retain the project's established stack when working on existing artifacts. A skill library change is not permission to migrate a user project or replace its assets.

## Produce and verify

Resolve useful text and asset choices before expensive rendering. Generate real outputs rather than placeholders unless explicitly requested. Verify dimensions, duration, required tracks, synchronization, readable text, and representative beginning/middle/end states as applicable. Inspect the rendered media, not only its source.

A request for a finished local video includes the necessary local render within the stated resource budget. Use collaborative checkpoints when the user chose them; do not ask for the same render authorization again. Paid/cloud execution, public uploads, feedback submissions, publication, voice/identity use, and licensing retain their actual permission boundaries.

Return a usable preview or output file, commands/checks actually run, and material limitations. Do not transmit artifacts, diagnostic logs, or feedback to third parties without authorization.
