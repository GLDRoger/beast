# Master tell catalog

Use these as diagnostic examples, not blanket bans or required passes. Preserve meaning, warranted uncertainty, quotations, and the user's intentional voice. Apply only the patterns that weaken the current piece.
Audit checklist. Detection = **density + co-occurrence**, not a single hit.

## Structure and rhetoric

- [ ] Insight announcement before delivery
- [ ] "Not X, it's Y" / negative listing / binary contrast theater
- [ ] Fake-precision triad (three oracle beats)
- [ ] Dramatic fragmentation ("X. That's it.")
- [ ] Rhetorical setups ("What if…?", "Think about it:")
- [ ] Setup → reframe → summary machine on every section
- [ ] Rule of three everywhere
- [ ] Question immediately answered every time
- [ ] Closing restates the whole piece
- [ ] Both-sides hedge ending / false balance
- [ ] Invented "framework" branding (3 C's, RISE method…)

## Throat-clearing and meta

- [ ] Here's the thing / Here's why / Let's dive in
- [ ] Let me be clear / The truth is / It turns out
- [ ] In this section we'll… / As we'll see… / Let me walk you through…
- [ ] Ever wondered…? / Have you ever…?
- [ ] Spoiler / Plot twist / Full stop / Let that sink in
- [ ] As mentioned above / Building on that
- [ ] Outline leaks as subtitles

## Vocabulary spikes

- [ ] delve, tapestry, testament, beacon, realm, symphony, nestled
- [ ] leverage, elevate, harness, foster, navigate, unpack, landscape
- [ ] seamless, robust, comprehensive, cutting-edge, groundbreaking
- [ ] supercharge, unleash, unlock, game-changer, craft (vague)
- [ ] pivotal/paramount/crucial stacked without numbers
- [ ] journey/transform/evolve for ordinary change
- [ ] honestly/simply/really/just/literally/genuinely/actually/deeply
- [ ] Furthermore/Additionally/Moreover/That being said/In conclusion

## Sentence and rhythm

- [ ] Metronomic sentence length
- [ ] Em dash addiction
- [ ] Semicolon polish throughout
- [ ] Three-item lists as default
- [ ] Perfect parallel structure on every bullet
- [ ] Every paragraph ends with a punchy one-liner
- [ ] Colon announcements on loop ("The result: X.")
- [ ] No contractions in casual prose (or forced casual that stays corporate)
- [ ] Uniform politeness temperature

## Voice and agency

- [ ] Abstractions doing human verbs
- [ ] False agency ("the decision emerges")
- [ ] Narrator-from-a-distance ("People tend to…")
- [ ] Passive hiding the actor
- [ ] Corporate we with no speaker
- [ ] Sycophantic warmth ("Great question!")
- [ ] Therapist cadence ("It's okay to feel…")
- [ ] No risk / no sharp opinion without a cushion
- [ ] No first-person texture (time, place, cost, embarrassment)
- [ ] "Users/people" where "you" belongs

## Content habits

- [ ] Restates scene/fact after showing it
- [ ] Research flex that doesn't change the claim
- [ ] Missing setup before payoff
- [ ] Unexplained jargon on first use
- [ ] Critic voice instead of showing the chain
- [ ] Announces excitement instead of selecting the fact
- [ ] Vague declaratives ("stakes are high")
- [ ] Generic examples (Alice/Bob, "imagine a company")
- [ ] Empty specificity (precise-sounding unchecked numbers)
- [ ] Safety-smoothed claims / false balance
- [ ] Benefits with no costs
- [ ] Moral-of-the-story button
- [ ] Advice that fits any topic

## Formatting surface (blogs / docs / LinkedIn)

- [ ] Emoji section headers in serious prose
- [ ] Bold every key phrase
- [ ] Title Case Feature Headings
- [ ] TL;DR that restates instead of decides
- [ ] Pull quotes that are aphorisms, not reader-implicating lines
- [ ] Tables for two-sentence ideas
- [ ] FAQ padding
- [ ] Key takeaways that are the article again
- [ ] Over-clean Markdown with zero lived-in asides

## Marketing / product copy

- [ ] "In today's fast-paced world/landscape"
- [ ] "Chaos into clarity" / X-into-Y slogans
- [ ] "No X. No Y. Just Z."
- [ ] "This doesn't just X — it also Y"
- [ ] "The part everyone gets wrong"
- [ ] Battle-tested / all-in-one / scale without limits
- [ ] Headline that could describe three different products
- [ ] Feature described by what it *is*, not what it *does*

## Chat-specific

- [ ] Permission-seeking ("Feel free to…")
- [ ] Over-validation
- [ ] Apology loops
- [ ] Menu of options when one answer was asked
- [ ] Refuses to be short (pads a one-liner into a post)
- [ ] Refuses to be long when needed (triple summary, no new depth)
- [ ] "As an AI…"
- [ ] Engagement bait endings

## Craft failures (long-form)

- [ ] Pronouns without antecedents / orphan fragments
- [ ] More than one raised voice (everything emphasized)
- [ ] Polished wrong facts
- [ ] Paragraph job is a hedge (rewrites stay throat-clearing)
- [ ] Form fights argument (neat list when accumulation is the point)
