# Structures to Avoid

## Binary contrasts

False drama. State the point directly.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." / "Not because X, but because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliché |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." / "not X, it's Y" / "isn't X, it's Y" | Mechanical contrast |
| "It's not this. It's that." | Same formula |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" | Negation-then-assertion |
| "is about X but not Y" | False distinction |
| "not just X but also Y" | Additive hedge |
| "This doesn't just X — it also Y" | Marketing contrast |

**Instead:** State Y. "The problem is Y." Drop the negation.

## Negative listing

| Pattern | Problem |
|---------|---------|
| "Not a X… Not a Y… A Z." | Dramatic buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same, past tense |

**Instead:** State Z.

## Fake-precision triad

Three parallel short claims that sound deep:

- "The target is hidden. The rules are known. The comparison is independent."
- Any three-beat oracle cadence without earned specificity

**Instead:** One concrete claim, or real evidence.

## Dramatic fragmentation

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |

**Instead:** Complete sentences. Trust content.

## Rhetorical setups

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |
| Question answered in the next line every time | Never lets a question breathe |

## Insight announcement structure

A sentence whose only job is to promise value before the next sentence delivers it.

- "Its deepest idea is structural. [then the idea]"
- "Look at how thin the evidence was. [then the evidence]"

**Instead:** Deliver the idea / evidence first.

## Section machine (setup → reframe → summary)

Every section the same shape: throat-clear → reframe → soft summary. Humans vary; models default.

## Rule of three everywhere

Three benefits, three reasons, three "not onlys." Prefer one or two items that are real.

## Perfect parallel bullets

"To X… To Y… To Z…" on every list. Vary openings; cut forced symmetry.

## Both-sides / false-balance ending

- Soft "of course X also has challenges… the key is balance…"
- Equal weight to weak counterpoints for the look of fairness
- Moral-of-the-story button

**Instead:** End on a sharper claim or implication. Don't restate the piece.

## Closing restatement

AI "conclusion" reflex: the last section says the article again in softer words.

**Instead:** New claim, cost, implication, or stop.

## Formulaic constructions

| Pattern | Problem |
|---------|---------|
| "By the time X, I was Y." | Narrative template |
| "X that isn't Y" | Indirect. Say "X is broken" |
| "The result: X." / "The answer: Y." on loop | Colon announcement factory |
| Invented frameworks (The 3 C's of…, The RISE method…) | Instant blog-slop |

## False agency

Inanimate things doing human verbs. AI loves this because it avoids naming the actor.

| Pattern | Problem |
|---------|---------|
| "a complaint becomes a fix" | Someone fixed it |
| "a bet lives or dies in days" | Someone kills or ships |
| "the decision emerges" | Someone decides |
| "the culture shifts" | People change behavior |
| "the conversation moves toward" | Someone steers |
| "the data tells us" | Someone reads and concludes |
| "the market rewards" | Buyers pay |
| "It refuses to flatten a complicated world…" | Abstraction performing ethics |

**Instead:** Name the human. "The team fixed it that week." Or use "you."

## Narrator-from-a-distance

| Pattern | Problem |
|---------|---------|
| "Nobody designed this." | Disembodied observation |
| "This happens because…" | Lecturer voice |
| "This is why…" | Same |
| "People tend to…" | Armchair sociologist |
| Corporate "We believe…" with no speaker | Fog |

**Instead:** Put the reader in the room. "You don't sit down one day and decide to…"

## Passive voice

| Pattern | Fix |
|---------|-----|
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |

## Sentence starters to avoid (as crutches)

| Pattern | Fix |
|---------|-----|
| What/When/Where/Which/Who/Why/How openers as default | Lead with subject or verb |
| Paragraphs starting with "So" | Start with content |
| Sentences starting with "Look," | Remove |
| "However," / "Furthermore," paragraph opens | Rework transition |

## Rhythm patterns

| Pattern | Fix |
|---------|-----|
| Three-item lists as default | Use two or one |
| Questions answered immediately every time | Let breathe or cut |
| Every paragraph ends punchily | Vary endings |
| Em dashes | Remove; commas or periods |
| Semicolon polish throughout | Rare; prefer periods |
| Staccato: seven short declaratives in a row | Let one sentence run |
| Comma-chaining the best fact mid-clause | Full stop for the sharpest fact |
| Metronomic sentence length | Mix long and short |
| Uniform politeness temperature | Allow sharp, uneven human tone |
| No contractions in casual contexts | Contract when speech would |

## Word patterns

| Pattern | Problem |
|---------|---------|
| Lazy extremes (every, always, never, everyone, nobody) | False authority |
| Empty adverbs (see phrases.md) | Empty emphasis |
| Two-word phrase repeated 2–3 times for rhythm | Manufactured cadence |

## Content structure failures

| Pattern | Fix |
|---------|-----|
| Restate scene/fact right after showing it | Continue from consequences |
| Research flex that doesn't change the claim | Footnote or cut |
| Setup missing before payoff | Plant the fact earlier, one clause |
| Generic examples (Alice/Bob, "imagine a company") | Real or cut |
| Benefits list with no costs | Honest tradeoff or omit |
| Advice that fits any topic ("start small", "be intentional") | Specific next action |
| Outline leaks as subtitles | Write the subtitle for a cold reader |
| Critic voice instead of showing the chain | Show recursion / sequence |
