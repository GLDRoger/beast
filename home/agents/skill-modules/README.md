# Specialist modules

Load a module from `~/.agents/skill-modules/<name>/SKILL.md` only when its concrete procedure helps the current task. Read only the relevant supporting references. Installation does not make every checklist, interview, or report format compulsory.

The primary workflows own completion. A standalone review remains read-only; a review used inside an authorized implementation returns its findings to that implementation.
