Get users to the **aha moment** fast. Teach the essential; respect skip and return visits.

## Prep

1. Invoke `$impeccable` Context Gathering Protocol.
2. Lock: aha moment, experience mix (beginner / power / mixed), time budget.

## Diagnose

- Where do users stall or drop?
- Minimum to be successful? Key first action?
- Motivation (exploring vs required) and prior tools they know?

## Principles

| Do | Don't |
|----|--------|
| Show with real product, not a fake tutorial mode | Force long gates before value |
| Progressive disclosure (one idea at a time) | Patronize or over-explain standards |
| Optional skip for experienced users | Replay dismissed tips |
| Teach at point of use (empty states, tooltips) | Dump every feature upfront |
| Track completion; never re-show | Hide Skip |

## Patterns (pick what fits)

**First-run:** clear value prop · minimal setup · 1–3 core concepts · first real success · honest time estimate · skip

**Empty states** (always): what will be here · why it matters · primary CTA · optional template · light visual

Types: first-use · user-cleared · no results · no permission · load error — each needs a different next action.

**Contextual tips:** first encounter only · point at the control · benefit in one line · dismiss + don't-show-again

**Tours:** only for complex IA or big redesigns · 3–7 steps · workflow language (“Create a project”) · sample data · replay from help

**Announcements:** what's new + why + try now · dismissable

## Implement lightly

- Persist seen/completed flags (localStorage or account prefs)
- Prefer real CTAs over dead demo chrome
- Measure: time-to-value, completion, skip rate, drop-off step

## Verify

Users reach aha quickly · know the next step · skip works · return users aren't re-onboarded · completion isn't artificially low from length
