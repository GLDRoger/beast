# Website → HyperFrames

This skill was demoted to a module. Canonical orchestration is **`$media`**.

1. Load `$media` (or read `~/.agents/skills/media/SKILL.md`).
2. Open module `~/.agents/skill-modules/hyperframes/SKILL.md` and route as a site/product showcase (usually product-launch-video).
3. Use `~/.agents/skill-modules/hyperframes-cli/SKILL.md` for capture/render CLI steps.
